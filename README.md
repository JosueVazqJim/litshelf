## 📍 Overview

<code>❯ LitSheLitShelf is a dynamic and user-friendly web application designed to provide book enthusiasts with a platform to discover, explore, and dive into the literary world. With LitShelf, users can browse through a curated collection of books, check ratings, and access essential book details such as descriptions, authors, subjects, and publication dates.lf is a dynamic and user-friendly web application designed to provide book enthusiasts with a platform to discover, explore, and dive into the literary world. With LitShelf, users can browse through a curated collection of books, check ratings, and access essential book details such as descriptions, authors, subjects, and publication dates.</code>

---

## 👾 Features

<code>❯ Search for books by title, author, or subject.</code>
<code>❯ View book descriptions, ratings, and metadata.</code>
<code>❯ Leave and read reviews for books.</code>
<code>❯ Optimized for desktop and mobile devices using Bootstrap and custom CSS.</code>

## 🚀 Getting Started

### ☑️ Prerequisites

Before getting started with litshelf, ensure your runtime environment meets the following requirements:

- **Package Manager:** Npm


### ⚙️ Installation

Install litshelf using one of the following methods:

**Build from source:**

1. Clone the litshelf repository:
```sh
❯ git clone https://github.com/JosueVazqJim/litshelf
```

2. Navigate to the project directory:
```sh
❯ cd litshelf
```

3. Install the project dependencies:


**Using `npm`** &nbsp;()

```sh
❯ npm install
```




### 🤖 Usage
Run litshelf using the following command:
**Using `npm`** &nbsp; [<img align="center" src="" />]()

```sh
❯ npm index.js
```
